# Kentekenjacht

Raadspel voor kinderen: van welk land komt dit kenteken? 43 landen, drie reizen (Buurlanden, Heel Europa, Wereldreis), stempels, een postzegelalbum en een wereldkaart.

## Starten

```bash
npm start
```

Open daarna http://localhost:5173. Op de tablet (zelfde wifi): http://<ip-van-je-mac>:5173.

Zonder Node: open `index.html` direct in de browser.

## Controleren

`dev/plates.html` laat alle kentekens, vlaggen en auto's zien.

## Kaart opnieuw bouwen

```bash
npm install
npm run maps
```

Kaartdata: Natural Earth via [world-atlas](https://github.com/topojson/world-atlas) (publiek domein).
